# Hero background video

Place your medical billing hero video here as:

`hero-billing.mp4`

The site tries this **local file first** (most reliable), then falls back to online sources.

## Recommended content
- Healthcare professional with tablet / computer
- Medical billing or analytics dashboard
- Hospital / clinic environment

## Free sources
- [Pexels — medical](https://www.pexels.com/search/videos/medical%20billing/)
- [Pexels — healthcare analytics](https://www.pexels.com/search/videos/healthcare%20data/)

Download an MP4, rename to `hero-billing.mp4`, and refresh the page.
